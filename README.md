# 🛒 Amazon AI Shopping Assistant

An AI-powered shopping assistant that recommends Amazon devices using Machine Learning and Large Language Models.

Built with **FastAPI**, **Transformers**, and **FLAN-T5**, the assistant combines structured analytics with Generative AI to help users choose the best product based on thousands of customer reviews.

> Developed as the deployment phase of the Ironhack AI Engineering Bootcamp.

## Project Overview

Amazon AI Shopping Assistant is an AI-powered recommendation system that helps users choose Amazon devices based on real customer reviews.

Instead of reading thousands of reviews, users can ask natural language questions and receive personalized buying recommendations generated by a Large Language Model (FLAN-T5).

The application combines the outputs of a complete NLP pipeline with Generative AI to provide concise, human-readable product recommendations.

---

## Background

This application is built on top of the Amazon Review NLP Pipeline developed during Ironhack Project 3.

The original project includes:

- Data Cleaning
- Sentiment Analysis (DistilBERT)
- Product Category Clustering (TF-IDF + K-Means)
- Generative Product Summaries (FLAN-T5)

The Shopping Assistant reuses the processed outputs rather than retraining models during inference.
